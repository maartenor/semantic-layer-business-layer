Data Layers

Business Layer

Describes data in business terms with business-friendly definitions and ownership information.

  • Customer data objects (Customer, Customer ID, Customer Name, Country)
  • Machine data objects (Machine, Machine Number, Machine Type, Model)

Logical Layer

Provides a 1-to-1 mapping from business logic to technical implementation, bridging the gap between business and technical views.

  • Logical customer entity with attributes
  • Logical machine entity with attributes

Technical Layer

Represents the physical storage in PostgreSQL database with actual table and column definitions.

  • customers table (customer_id, customer_name, country)
  • machines table (machine_nr, customer_id, machine_type, model)

API Endpoints

Access the REST API at the following endpoints:

  • GET /api/v2/assets - List all assets
  • GET /api/v2/assets/{assetId} - Get specific asset
  • GET /api/v2/domains - List all domains
  • GET /api/v2/relations - List all relationships
  • GET /health - Health check
